# ThreatEye Detection Rules

Community KQL detection rules generated by the ThreatEye CTI Platform.

## Structure

- `rules/by-actor/` — Rules organized by threat actor (APT29, FIN7, Lazarus, etc.)
- `rules/by-tactic/` — Rules organized by MITRE ATT&CK tactic
- `rules/by-cve/` — Rules targeting specific CVE exploits
- `rules/by-platform/` — Rules by SIEM platform (Sentinel, Splunk, Sigma)

## Rule Format

Every rule includes a standardized header:
- Rule name, author, created date
- Platform and severity
- MITRE ATT&CK technique mapping
- Threat actor attribution
- CVE identifiers where applicable
- Plain English description

## Contributing

Rules are generated by ThreatEye and reviewed before publishing.
All rules are provided as-is for detection and hunting purposes.
